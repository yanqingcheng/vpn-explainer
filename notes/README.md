# Learning notes

Qing's notes from learning networking, Tailscale and Go while building this page. Public, like the rest of the repo.

## Layout

- `notes/<topic>/index.md`: the learning path for that topic (proposed, then endorsed by Qing).
- `notes/<topic>/YYYY-MM-DD-<description>.md`: session notes, questions, attempts. Messy is fine.
- `notes/<topic>/knowledge/<concept>.md`: one concept per note, only for things Qing has shown or endorsed she understands. Should be revisable from cold.

Topics so far (folders are created at the first real session, not in advance):

- [`vpns-and-tailscale`](vpns-and-tailscale/index.md): IP routing up to tailnets, DERP and the control plane
- `go`: the language itself

Filenames are kebab-case. Link between notes freely, and from notes back to the step of the page they belong to.
